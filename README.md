# Sistema de Cadastro de Clientes em Python

Aplicação simples em Python executada no terminal para cadastrar e listar clientes em memória.

## Funcionalidades

- Cadastrar novos clientes com validação para impedir nomes em branco.
- Listar clientes cadastrados com numeração automática.
- Menu interativo no terminal com pausa após cada ação.

## Como executar

1. Tenha o **Python 3** instalado no computador.
2. Baixe ou clone este repositório.
3. No terminal, dentro da pasta do projeto, execute:

```bash
python app.py
